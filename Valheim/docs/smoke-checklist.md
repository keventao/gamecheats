# EasySpawner 汉化版 — 游戏内烟雾检查清单

每次上游同步 / 词条改动后，在** disposable 测试存档**中过一遍。

## 加载

- [ ] BepInEx 日志无报错，出现 `Easy spawner: Easy spawner loaded plugin`
- [ ] 无 Harmony patch 失败 / TypeLoadException

## 菜单基础

- [ ] 进入存档后按 `/` 呼出菜单，再按关闭
- [ ] 标题显示「简易生成器」，无方块 / 缺字
- [ ] 「快捷键:」及三行热键提示（打开/关闭、生成、撤销）为中文，修饰键显示 Ctrl 等
- [ ] 搜索框占位符「搜索...」、数量「数量...」、等级「等级...」
- [ ] 按钮「生成」、三个勾选项「放入背包」「忽略堆叠上限」「只看收藏」
- [ ] 所有中文无截断、无重叠；有截断记录控件名

## 功能（与汉化无关，确认未改坏）

- [ ] 搜索 `copper` 同时能匹配英文名与中文名（铜），列表项显示「中文名 (PrefabName)」
- [ ] 选物品 + 数量 + 等级，点「生成」，左上角提示「正在生成 xxx」
- [ ] 勾「放入背包」只对自己、只对物品生效
- [ ] 勾「忽略堆叠上限」可超过正常堆叠
- [ ] Ctrl+Z 撤销，居中提示「已撤销生成 N 个 <name>」
- [ ] 生成不存在的名字（理论上无法从列表选，仅日志/消息回归）显示「xxx 不存在」

## 字体回归

- [ ] 系统存在微软雅黑时使用之；缺失时按回退链（黑体 / 宋体等）仍能正常显示中文
- [ ] 本汉化为无条件替换：游戏切英文，菜单仍是中文（汉化 fork 的预期行为；要英文请换回上游 DLL）
